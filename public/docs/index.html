Quick start

Get it running locally

You'll need Node 18+ (Node 20 recommended) and npm.

Get the code

Clone the repository (or download it as a ZIP).

bash
git clone https://github.com/codespanda/finovo.git
cd finovo

Install dependencies

bash
npm install

Start the dev server

Vite serves the app at http://localhost:5173 with hot reload.

bash
npm run dev
The @ alias points to src/, so imports look like import { Button } from '@/components/ui/button'.

Deploy

Deploy to GitHub Pages

This project ships with a GitHub Actions workflow that builds and deploys straight to GitHub Pages on every push to main — no gh-pages branch to manage.

Real routes on a static host

GitHub Pages has no server-side rewrites, so a hard navigation to a nested route like /sales would 404 before React Router ever sees it. Finovo keeps BrowserRouter (real paths, no #) and instead ships a small SPA fallback: public/404.html redirects unknown paths back to index.html, which restores the original URL — the classic spa-github-pages trick.

Enable Pages

In your repo: Settings → Pages → Build and deployment → Source, then choose GitHub Actions.

Push

The workflow in .github/workflows/deploy.yml builds with npm ci && npm run build and publishes dist/ via actions/deploy-pages.

bash
git push origin main
Using a custom domain? Add it to public/CNAME so it survives every redeploy — Finovo's is set to finovo.codespanda.com. Live at finovo.codespanda.com.

Theming

Theming & dark mode

Theming uses Tailwind's dark class strategy. Colors are OKLCH CSS custom properties defined in src/index.css and toggled by adding .dark to the document root — handled by ThemeProvider, which persists the choice to localStorage.

css
:root {
  --primary: oklch(0.55 0.22 262);   /* blue */
  --background: oklch(1 0 0);
  --foreground: oklch(0.21 0.03 265);
  --sidebar: oklch(1 0 0);
}
.dark {
  --primary: oklch(0.55 0.22 262);
  --background: oklch(0.16 0.02 265);
  --foreground: oklch(0.95 0.01 260);
  --sidebar: oklch(0.19 0.02 265);
}
To change the brand color, update the --primary values in src/index.css.
